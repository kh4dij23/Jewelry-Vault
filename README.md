Jewelry Vault

Project Description:
Jewelry Vault is an Android mobile application developed as a Mobile App Development (MAD) course project.  
The app helps users manage and store jewelry item information digitally.

Features
-User Login & Registration
-Add Jewelry Items
-View Jewelry Collection
-Simple and user-friendly interface

Technologies Used
-Java
-XML
-SQLite Database
